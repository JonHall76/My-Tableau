# My-Tableau

📊 Tableau Project: Global Health Insights Dashboard
A Data Technician Bootcamp Project
This project was completed as part of a Data Technician bootcamp and focuses on developing core Tableau skills through hands‑on analysis and visualisation of global health data. Using the Gapminder Health dataset, the project explores trends in life expectancy, population, and key health metrics across countries and continents.
The final output is an interactive Tableau dashboard designed to support effective data storytelling and help organisations quickly understand patterns, disparities, and opportunities in global health.

🚀 Project Overview
The aim of this project was to:

Build interactive dashboards using Tableau.
Apply Tableau features such as filters, slicers, sort controls, calculated fields, and table calculations.
Use a variety of chart types to visualise health, retail, and demographic data.
Develop skills in data storytelling, creating visuals that inform real‑world decision‑making.
Publish the completed dashboard to Tableau Public.


📈 Key Visualisations
The Tableau dashboard includes the following components:
1. Life Expectancy by Continent (Bar Chart)

Shows average life expectancy for each continent.
Includes sorting and a filter for the most recent available year.

2. Life Expectancy Trend (Line Chart)

Highlights long‑term trends for the top 5 countries with the highest life expectancy.
Interactive colour‑coded lines for easy comparison.

3. Population Distribution by Gender (Pie Chart)

Displays gender distribution for a selected country.
Includes filters and percentage of total table calculations.

4. Life Expectancy vs BMI (Scatter Plot)

Explores the relationship between life expectancy and BMI.
Colour‑coded by continent with interactive filtering.

5. Additional Custom Visualisation

Includes an extra chart to further enhance the overall analysis.

All visuals are combined into a single, fully interactive Global Health Dashboard.

🧰 Skills Demonstrated
This project demonstrates practical competence in:

Building multi‑sheet Tableau dashboards
Designing interactive filters, slicers, and dropdown selectors
Creating calculated fields and applying table calculations
Using a range of visualisation types (bar, line, pie, scatter, map)
Data storytelling & insight communication
Publishing professional dashboards to Tableau Public


🔗 Tableau Public Dashboard
View the live dashboard here:

📚 Insights & Reflections
The dashboard highlights global differences in life expectancy, BMI, and gender‑based population structure.
These insights can inform how large health organisations (such as the NHS) compare their outcomes with high‑performing countries and identify strategies that contribute to better health metrics.
